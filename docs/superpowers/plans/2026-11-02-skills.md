# Skills Management Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement task-by-task.

**Goal:** List and toggle local Codex skills from an independent Web navigation entry.
**Architecture:** Reuse app-server skills/list and skills/config/write through HybridCodexRunner, AccountManager and protected HTTP routes. Render deduplicated skill metadata and scan errors in the existing vanilla Web UI.
**Tech Stack:** TypeScript, Node HTTP, vanilla JS/CSS; no new runtime dependencies.
**Spec:** docs/superpowers/specs/2026-11-02-skills-design.md

## Global Constraints
- Modify local Codex configuration; preserve repository release version.
- Keep the current visual system and authentication/mutation checks.

## Review Focus
- Duplicate paths across workspaces: merge into one entry.
- Invalid or unknown paths: reject before writing configuration.
- Failed writes: retain original switch state and show error.
- Failed scan: report error and allow retry.
- Long descriptions and paths: wrap on mobile.
